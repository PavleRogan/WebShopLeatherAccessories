# Leather Accessories E-Commerce App

This is a full-stack e-commerce application built using Angular for the frontend and .NET for the backend. The app is designed to provide a seamless shopping experience for leather accessory.

## Key Features

- **Modern User Interface:** Built with Angular, featuring a responsive and user-friendly design.
- **Product Management:** Comprehensive catalog of leather accessories with search, filter, and sorting capabilities.
- **Secure Checkout:** Integration with secure payment gateways and order management.
- **User Accounts:** Supports user registration, login, and personalized shopping experiences.
- **Admin Dashboard:** Manage products, categories, and orders with ease.
- **Backend:** Powered by .NET, ensuring fast and reliable performance.

## Technologies Used

- **Frontend:** Angular with Angular Material for a sleek UI.
- **Backend:** .NET Web API for robust business logic and data processing.
- **Database:** SQL Server for secure and efficient data storage.
